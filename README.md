# EventHub
Небольшое веб-приложение, где пользователи могут просматривать и регистрироваться на мероприятия.

**Требования**
- Python 3.10 или новее. При установке на Windows отметьте галочку **Add python.exe to PATH**. Вместе с Python устанавливается и pip.

**Запуск проекта**
1. В командной строке перейдите в папку репозитория, а затем в папку project.
2. Установите зависимости, введя в консоль команду pip install -r requirements.txt.
3. Создайте таблицы в базе данных, введя команду python manage.py migrate.
4. Создайте администратора: python manage.py createsuperuser. Нужно будет записать логин и пароль.
5. Запустите сервер: python manage.py runserver.
6. Откройте главную страницу http://127.0.0.1:8000/. На ней показаны три ближайших опубликованных мероприятия.
7. По кнопке «Все мероприятия» или через навигацию можно перейти на страницу http://127.0.0.1:8000/events/ со всеми мероприятиями, упорядоченными по дате. 
8. Для входа в админ-панель откройте http://127.0.0.1:8000/admin/ и введите логин и пароль, созданные на шаге 4.
9. Чтобы добавить мероприятие, в админ-панели нажмите **Add** рядом с разделом мероприятий, заполните данные, поставьте галочку «Опубликовано» и сохраните.
