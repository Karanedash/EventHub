# EventHub
Небольшое веб-приложение, где пользователи могут просматривать и регистрироваться на мероприятия.

**Требования**
- Python 3.10 или новее. При установке на Windows отметьте галочку **Add python.exe to PATH**. Вместе с Python устанавливается и pip.

**Запуск проекта**
1. В командной строке перейдите в папку репозитория, а затем в папку project.
2. Установите зависимости, введя в консоль команду pip install -r requirements.txt.
3. Введите команду для генерации случайного ключа python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())". Создайте файл с настройками .env и заполните его как в шаблоне .env.example
4. Создайте таблицы в базе данных, введя команду python manage.py migrate.
5. Загрузите демонстрационные мероприятия: python manage.py loaddata demo_events.
6. Создайте администратора: python manage.py createsuperuser. Нужно будет записать логин и пароль.
7. Запустите сервер: python manage.py runserver.
8. Откройте главную страницу http://127.0.0.1:8000/. На ней показаны три ближайших опубликованных мероприятия.
9. По кнопке «Все мероприятия» или через навигацию можно перейти на страницу http://127.0.0.1:8000/events/ со всеми мероприятиями, упорядоченными по дате.
10. Чтобы записаться на мероприятие, нужно нажать на подробнее в карточке, а затем заполнить форму и нажать на кнопку регистрации.
11. Для входа в админ-панель откройте http://127.0.0.1:8000/admin/ и введите логин и пароль, созданные на шаге 6.
12. Чтобы добавить мероприятие, в админ-панели нажмите Add рядом с разделом мероприятий, заполните данные, поставьте галочку «Опубликовано» и сохраните.
13. Чтобы посмотреть заявки, в админ-панели нужно открыть раздел регистраций. Администратор может менять статус заявок.
